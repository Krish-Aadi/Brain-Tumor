3. System Architecture & Engineering Design

10 MARKS
🗣️ What to Speak in Presentation / Viva: "Our system architecture features a decoupled, high-performance pipeline. Input MRI scans (124x124) undergo CLAHE contrast enhancement in LAB color space. The image is passed simultaneously into a 4-layer PDSCNN branch generating 256 spatial features, and a Vision Transformer branch dividing a padded 128x128 representation into 16x16 patches generating 128 global features. The concatenated 384-dimensional vector is classified in a single closed-form step by our Regularized Ridge ELM (C = 500.0). Backend is powered by PyTorch and Flask; frontend is built on React 19 and Vite."

6. Top Viva Defense Questions & High-Scoring Answers

EXAMINER Q&A

Q1: Why use RRELM instead of Softmax MLP?

Answer: Softmax MLPs require iterative backpropagation across hundreds of epochs, risk local minima, and overfit easily. RRELM uses 4,096 randomized hidden neurons and computes output weights analytically via Ridge pseudo-inversion: β = (Hᵀ H + C · I)⁻¹ Hᵀ Y, achieving sub-second training and superior generalization.

Q2: Why combine CNN with Vision Transformer?

Answer: CNNs have an inductive bias for local spatial features (lesion margins, texture) but lack long-range contextual awareness. ViT divides images into patches and models global spatial dependencies via multi-head self-attention. Concatenating both (256-d + 128-d = 384-d) creates a robust local-global representation.

Q3: What is the purpose of CLAHE?

Answer: MRI scans exhibit intensity variations across scanners. Global histogram equalization over-amplifies noise. CLAHE operates on localized 8×8 grid tiles in LAB lightness channel with a clip limit of 2.0, sharpening tumor boundaries without magnifying background artifacts.

Q4: How does Dual Explainable AI work?

Answer: 1. Multi-Scale Grad-CAM on Conv3+Conv4 provides fine-grained local lesion boundaries (JET colormap). 2. ViT Attention Rollout displays global patch dependencies (MAGMA colormap). 3. Morphological cranial masking removes outer skull artifacts.
